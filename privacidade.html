Privacidade

Política de Privacidade

Esta página explica quais dados são coletados neste site, para que são usados e quais são os seus direitos. Última atualização: setembro de 2026.

Quais dados são coletados

Dados que você informa

Ao solicitar um orçamento ou uma mentoria, você informa nome ou identificação, e-mail ou número de WhatsApp, e as informações que escrever sobre o seu projeto.

Nenhum desses campos é obrigatório além do necessário para eu conseguir responder você.

Dados de navegação

O site pode registrar dados agregados de acesso, como páginas visitadas e origem do tráfego, sem identificar você individualmente.

Os players de áudio são incorporados do Spotify, que aplica as próprias políticas de cookies.

Como os dados são usados

Finalidade

Os dados de contato são usados exclusivamente para responder à sua solicitação e conduzir o projeto, caso ele aconteça.

Compartilhamento

Seus dados não são vendidos, alugados nem compartilhados com terceiros para fins comerciais.

Seu material de áudio nunca é divulgado publicamente sem sua autorização.

Por quanto tempo

As mensagens são mantidas enquanto forem necessárias para o atendimento e para o histórico do projeto.

Você pode pedir a exclusão a qualquer momento.

Seus direitos

O que você pode solicitar

Conforme a Lei Geral de Proteção de Dados (LGPD), você pode solicitar a qualquer momento:

  • Confirmação de que seus dados são tratados
  • Acesso aos dados que possuo sobre você
  • Correção de dados incompletos ou desatualizados
  • Exclusão dos seus dados
  • Revogação do consentimento

Como exercer

Basta escrever para studio@lucaslusaudio.com informando o que você precisa.

Respondo normalmente no mesmo dia útil.

Quem é o responsável

O controlador dos dados tratados neste site é Lucas Lus, pessoa física, que atua profissionalmente sob o nome Lucas Lus Audio.

Contato para assuntos de privacidade: studio@lucaslusaudio.com.
